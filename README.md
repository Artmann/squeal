<h1 align="center">Squeal – A Delightful SQL Client</h1>

## 🔌 Connect to Your Databases

- Connect to PostgreSQL databases
- Manage multiple database connections

## ✨ Write Queries with Joy

- Write multiple queries in a scratchpad and run only the one under your cursor
- Smart autocomplete suggestions
- Keyboard shortcuts for fast execution

## 📊 View Results Instantly

- See your data in a clean, scrollable table
- Track your query history

## 📁 Stay Organized

- Organize queries into worksheets
- Switch databases on the fly

## 🎨 Beautiful by Default

- Modern, beautiful themes in both light and dark mode
- Native desktop experience
